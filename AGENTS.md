# Next.js version note

This project runs a standard, published Next.js release (currently 15.x,
App Router) — there is no custom fork and no `node_modules/next/dist/docs/`
folder to consult; that path doesn't exist in this package. If you're
unsure about an API, check the version pinned in `package.json` against
the public Next.js docs for that version, and watch for App Router
breaking changes when upgrading across major versions.
